## Rules / requirements

- Build an MVP using anything in the MagicBlock stack: zero-fee Ephemeral Rollup transactions,
  VRF (verifiable randomness), privacy (Private Ephemeral Rollups), automation.
- Blitz rule: **every submission must integrate Ephemeral Rollups.**
- **Mainnet is not required.** The submit page checks "recent devnet and mainnet activity" for
  on-chain addresses — devnet counts.
- Team size: not stated. Solo is fine; teammates via build.magicblock.app/builders.

## Judging (what we optimize for)

Reported criteria for Blitz: **creativity, technical depth, and how clearly the project shows what only
real-time Solana can do.** Earlier editions also judged on how meaningfully the project uses MagicBlock's
infrastructure. Optional submission fields "strengthen your submission and improve your chances."
